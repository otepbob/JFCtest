Setup Guide & Integration Instructions

☁️ 3-Minute Microsoft OneDrive Setup Guide (Power Automate):

  1. In your OneDrive for Business / SharePoint, create an Excel file named Jabra_Floorwalk_Logs.xlsx.
  2. Inside the file, create a Table (select cells and press Ctrl+T) named FloorwalkTable with columns:
    Record_ID, Inspection_Date, Inspection_Time, Inspector, Building, Floor, Huddle_Room, Status, Remarks, Checked_Time, Submitted_At
  3. Go to make.powerautomate.com → Create → Instant cloud flow → Choose When an HTTP request is received.
  4. In the trigger, paste the JSON payload schema below (click "Copy Payload Schema").
  5. Add an action: Excel Online (Business) > Add a row into a table:
    - File: Select your Jabra_Floorwalk_Logs.xlsx in OneDrive
    - Table: Select FloorwalkTable
    - Map the row parameters to the trigger's details array.
  6. Save the Flow, copy the generated HTTP POST URL, and paste it into the URL field above!

Remarks & Operational Guide

Button Functionality Reference (From Excel Macro)
